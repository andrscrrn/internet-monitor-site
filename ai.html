Ask your AI about your internet

Internet Monitor includes an MCP server, so Claude, ChatGPT or any MCP-compatible assistant can answer questions about your connection from your local data.

What you can ask

  • "How was my internet this week?"
  • "When was my last outage and how long did it last?"
  • "Compare my home and office networks."
  • "Should I complain to my ISP? Make the case with my data."

Claude Desktop (one click)

Download the extension and double-click it: Claude Desktop installs it with the app's name and icon. That's it. You will find it under Settings → Connectors.

ChatGPT Desktop and other MCP clients

Point the client at the server bundled inside the app:

/Applications/Internet Monitor.app/Contents/MacOS/internet-monitor-mcp

For clients configured by JSON (an mcpServers map), the entry is:

{"Internet Monitor": {"command": "/Applications/Internet Monitor.app/Contents/MacOS/internet-monitor-mcp"}}

What the assistant can see

Five read-only tools: current status, uptime summaries, the outage list, latency statistics, and the networks you have used, for periods up to 30 days and filterable per network. The server reads the app's local files only, works even when the app is closed, opens no network port, and sends nothing anywhere. Your assistant's own privacy policy governs what happens to the answers it generates.

Troubleshooting

  • The Internet Monitor app must be installed in Applications; the extension runs the server bundled inside it.
  • After installing, fully restart the assistant app so it picks up the new connector.
  • No data yet? The app needs a little monitoring time before there is history to ask about.
  • Installed the extension with app version 1.0 and it never connects? That extension looked for the app in the wrong place. Fix it with one click: update the app, open Settings > AI Assistants, press "Install Claude Extension" again (it updates the existing one), and restart your assistant. Or reinstall the extension from the link above, which is already fixed.
